# MANUFACTURE — живая фабрика v0.2

Браузерный прототип без сборщика и зависимостей. Запуск: `npm start`, затем http://127.0.0.1:4173. Node.js 20+. Проверки: `npm test`.

## Правила версии 0.2

- Пустое поле 6×6; в каталоге производитель меди и крафтер с гарантированным общим резонансом. Начальный склад пуст.
- Семь ресурсов: медь, железо, сталь, золото, платина, титан, космический сплав. Предел каждого — 9999.
- Крафтер — контроллер четырёх соседей, без собственного выпуска и рецептов.
- Маршрут A: производитель → крафтер → склад. Маршрут B: производитель → локальный буфер сборщика → крафтер → склад. Сборщики не берут сырьё со склада.
- Производитель: 1 ресурс за 2 с. Сборщик: 2 сырья списываются при старте, 1 готовый ресурс через 3 с. Буфер следующего цикла — 2.
- Усилитель удваивает выпуск, не меняя длительность. Эффект фиксируется на старте, не складывается; потеря последнего усилителя отменяет усиленный цикл.
- Четыре случайных резонанса на каждой стороне. Поворот на 90° бесплатный; смена всех сторон — 5 меди. Для медника при запасе меньше 5 меди — бесплатно.
- Магазин содержит восемь покупок; цены и недостающее сырьё показаны постоянно. Покупки не ограничены.
- Мощность 120, каждый размещённый слизень занимает 10. Перегрузка отменяет циклы, сохраняя буферы.
- Получатели обслуживаются по очереди сверху, справа, снизу, слева. Выпуск не дублируется, переполнение теряется.
- Цикл сохраняется, пока остаётся хотя бы один прежний незатронутый полный маршрут. При разрыве всех маршрутов буфер очищается.
- Перетаскивание на занятую клетку меняет слизней местами; перенос из каталога возвращает прежнего обитателя в каталог. ПКМ или кнопка убирает слизня с поля.
- Симуляция учитывает реальное время, включая скрытую вкладку и перезагрузку; шаг 0,1 с. Завершения выполняются по строкам поля, затем стартуют новые циклы.
- «Начать сначала» сразу сбрасывает весь тест. Сохранения v0.2 отдельные: старое сохранение v0.1 остаётся в браузере, но не переносится из-за изменения правил.
- Основной интерфейс помещается на одном экране. При малом окне весь интерфейс пропорционально уменьшается; на телефоне текст может быть мелким.

## Структура

`src/data.mjs` — виды и магазин; `connections.mjs` — геометрия; `engine.mjs` — симуляция; `effects.mjs` — усиление; `app.mjs` и `style.css` — интерфейс; `fit.mjs` — масштабирование. Проверки в `tests/engine.test.mjs`.

Механический референс: Monster Girl Factory. Интерфейс и векторные слизни оригинальные. Шрифт Golos Text загружается из Google Fonts, запасной — системный.
